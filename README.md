# UNO 卡牌（小米手环 10 Pro）· 激活码兑换站点

本目录就是可以直接发布到 **GitHub Pages** 的站点根目录。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 站点全部内容（HTML / CSS / JS / 图片 / 兑换码校验数据全部内联在这一个文件里） |
| `.nojekyll` | 告诉 GitHub Pages 跳过 Jekyll 处理，原样发布静态文件 |

站点是 **纯静态单文件**：不依赖服务器、不依赖外部网络资源、不写入任何数据、不收集任何信息。
买家打开网址后，把「兑换码 + 手环设备码」填进表单，即可在浏览器本地算出该手环专属的激活码。
所有校验都在买家自己的设备上完成，卖家不需要任何后台服务器。

## 一、发布步骤（约 3 分钟）

### 方式 A：新建仓库，用根目录发布（推荐）

1. 登录 GitHub，新建一个仓库，例如 `uno-activation`。
   - 可见性选 **Public**（Pages 免费版要求公开仓库；私有仓库要付费套餐才能开 Pages）。
2. 把本目录的**全部内容**（`index.html`、`.nojekyll`、本 `README.md`）上传到该仓库的 **根目录**。
   - 网页上传：仓库首页 → `Add file` → `Upload files` → 把两个/三个文件拖进去 → `Commit changes`。
   - 或命令行：
     ```
     git init
     git add index.html .nojekyll README.md
     git commit -m "uno activation site"
     git branch -M main
     git remote add origin https://github.com/<你的用户名>/<仓库名>.git
     git push -u origin main
     ```
3. 仓库 → `Settings` → 左侧 `Pages`。
   - `Source` 选 **Deploy from a branch**
   - `Branch` 选 **main**，目录选 **/ (root)**
   - 点 `Save`
4. 等 1–2 分钟，页面顶部会出现站点地址，形如：
   ```
   https://<你的用户名>.github.io/<仓库名>/
   ```
   打开即见激活页面。

### 方式 B：用仓库里的 `/docs` 目录发布

1. 仓库根目录下新建 `docs/` 文件夹，把 `index.html` 与 `.nojekyll` 放进去。
2. `Settings` → `Pages` → `Branch` 选 `main`，目录选 **/docs**。
3. 地址同样是 `https://<你的用户名>.github.io/<仓库名>/`。

> 说明：用 `/docs` 方式时，`.nojekyll` 也放进 `docs/` 里即可。

### 自定义域名（可选）

在 `Settings` → `Pages` → `Custom domain` 填入自己的域名，并在域名服务商处按 GitHub 提示配置 CNAME 解析。
自定义域名要求仓库里有 `CNAME` 文件（GitHub 保存设置时会自动生成）。

发布成功后，把站点地址和自己的收款/发放渠道一起写进商品页或私信话术，例如：

> 感谢购买《UNO 卡牌（小米手环 10 Pro）》。
> 1. 在手机浏览器打开：`https://<你的用户名>.github.io/<仓库名>/`
> 2. 把手环上看不到的朋友，这里是流程：先在手环上打开 UNO 应用，未激活时会显示一串 **设备码**（16 位）。
> 3. 把「你的兑换码」和手环上的「设备码」填进网页，点「生成激活码」。
> 4. 复制得到的激活码，到手环上输入并确认，即可解锁完整版。

小提示：手环上输入激活码时，中间的连字符可以省略。

## 三、兑换码怎么发（爱发电）

- 本批次共 **500 个**兑换码，一码对应一次激活，清单见卖家侧的兑换码表格（含序号、兑换码、使用状态列）。
- 每卖出一份，从清单里取一个**尚未使用**的兑换码发给买家，并在表格里把该行状态标记为「已使用」。
- 爱发电的自动发货 / 私信发码请在你自己的账号侧操作；本仓库不包含也不托管任何发放逻辑。
- 建议在商品描述里写明「一码一人，请勿转发」。

## 四、必须让买家知道的两件事（建议原样保留在商品页）

1. **每个兑换码只能用一次。**
   这个网页是纯静态页面，**不联网、不记录**，所以它无法知道某个兑换码是否已被别人用过。
   请务必让买家不要把自己的兑换码转发给他人；否则同一码会被重复使用，卖家侧无法自动拦截。
   （使用状态由卖家在兑换码表格里人工登记。）

2. **激活码是和手环绑定的。**
   激活码由「兑换码 + 该手环的设备码」共同决定，**换了手环就需要重新用兑换码生成一次新激活码**。
   如果买家换了新手环，请按你的售后规则决定是否补发兑换码。

## 五、常见问题

**Q：必须开 GitHub Pages 吗？**
不是。这个目录是纯静态的，任何静态托管（Cloudflare Pages、Netlify、Vercel、对象存储、自己的服务器）都能直接发布。用 GitHub Pages 只是因为免费、省事。

**Q：会不会有隐私或合规问题？**
页面不发起任何网络请求、不写入本地存储、不使用 Cookie，全部计算在浏览器内存中完成，关掉页面即消失。仓库里也**不包含任何明文兑换码**——只保存了加盐哈希，即使页面源码被人查看，也拿不到可用兑换码。

**Q：页面打不开 / 样式错乱？**
确认上传的是 `index.html` 本体（约 700KB，单文件），且上传到了 Pages 指定的目录（根目录或 `/docs`）。不要用记事本另存为，避免文件被改动。

**Q：想改页面内容怎么办？**
`index.html` 是构建产物，不建议手工编辑。请改站点的源文件后重新构建，不要直接在发布文件上改字。
